# SkyCraft YS coop.3: установка и проверка сетевой игры

Сборка `0.1.2-ys.coop.3`: совместимость со Skyrim Together Reborn, свой участок карты для каждой
локации Skyrim, исправленное залипание клавиш и игра через Steam без Radmin (SkyCraft Link).
**JAR и DLL ставятся только вместе и у обоих игроков одинаковые:** протокол общей памяти
изменился (13), старая DLL с новым JAR не заработает.

Окружение то же, что раньше: Skyrim SE 1.7.104, SKSE 2.3.1, Address Library, MO2, Minecraft
26.3 (Fabric Loader 0.19.5, Fabric API 0.161.0+26.3, Java 25). Skyrim Together Reborn 1.8.4 —
по желанию, для общих NPC и квестов.

## Установка

Сначала сделайте копию сохранений Skyrim; для проверок используйте отдельное сохранение.

**SkyCraft уже стоит (обновление):**
1. Закройте Skyrim и Minecraft.
2. MO2 → включённый мод SkyCraft → «Открыть в проводнике» → `SKSE\Plugins`. Замените
   `SkyCraft.dll` файлом из `отдельно\`.
3. Prism → ПКМ на экземпляре SkyCraft → «Папка Minecraft» → `mods`. Удалите старый
   `skycraft-fabric-*.jar`, положите новый из `отдельно\`. Fabric API оставьте.
4. Если SkyCraft сам распаковывал комплект Minecraft в `%LOCALAPPDATA%\SkyCraft`, обновите JAR
   и там (папка `...\instances\SkyCraft\.minecraft\mods`).

**Новая установка:**
1. MO2 → «Установить мод из архива» → `SkyCraft-YS-0.1.2-ys.coop.3-MO2.zip`. Включите его и
   Address Library; другую копию SkyCraft отключите.
2. Запустите Skyrim через SKSE из MO2. SkyCraft сам распакует Minecraft в
   `%LOCALAPPDATA%\SkyCraft` и запустит его. При первом запуске войдите в Microsoft-аккаунт
   с Minecraft Java.

Проверка версии: в Minecraft нажмите T и введите `/skycraft debug status`.

## Подключение

**Через Steam (рекомендуется).** Оба в Steam и друзья. Хост: в своём мире O → «SkyCraft: сеть»
→ «Steam: друзья» → «Открыть свой мир друзьям в Steam». Гость: там же «Найти друзей с открытым
миром» → «Войти к …». Подробности и ошибки — `docs/YS-STEAM.md`. Пока идёт игра, Steam
показывает «Spacewar» — так и должно быть.

**Через Radmin/LAN.** Хост: «SkyCraft: сеть» → «Открыть свой мир для друга» → «Копировать
IP:порт» (выберите адрес Radmin) → передайте другу. Гость: вставить в верхнее поле →
«Подключиться». Брандмауэр хоста должен пропускать Java на этот порт.

**Skyrim Together (по желанию).** Запускайте Skyrim через `SkyrimTogether.exe` (из MO2).
Хост запускает сервер STR (порт 10578). Гость в окне подключения STR указывает: через Steam —
`127.0.0.1:10578` (адрес напишется в чате), через Radmin — IP хоста и `10578`.

## Что проверить во время игры

Отмечайте «да / нет / как именно» и, если что-то не так, время и что делали. После сессии
каждый собирает журналы (ниже).

### 1. Подключение
- [ ] Гость вошёл в мир хоста с первого раза; сколько секунд заняло.
- [ ] Хост видит в чате «… подключился»; оба видят друг друга.
- [ ] Гость выходит (`/leave`) и входит снова — без ошибок.
- [ ] Через Steam: ни у кого не понадобились Radmin и порты.

### 2. Управление и клавиши (раньше залипали)
- [ ] 10 минут обычной игры: бег, прыжки, бой, быстрые нажатия нескольких клавиш сразу —
      персонаж не продолжает идти сам, кнопки не «залипают».
- [ ] Alt+Tab у хоста: у гостя ничего не дрожит и не дёргается.
- [ ] Открыть/закрыть инвентарь и чат Minecraft во время движения — после закрытия
      ничего не нажато само.

### 3. Мир и локации (новое: каждая локация на своём участке)
- [ ] Хост и гость **в разных местах** (один в Вайтране, другой в пещере/доме) — оба играют,
      никого не «замораживает».
- [ ] Гость заходит в ту же локацию, что хост: видят друг друга на своих местах.
- [ ] Разрушение/копание у одного видно второму в той же локации.
- [ ] Двери, в том числе открытые/взломанные: можно пройти.
- [ ] Выброшенные предметы рядом с гостем в другой локации не проваливаются.

### 4. Бой и смерть
- [ ] Удары по NPC и от NPC наносят разумный урон (тролль не убивает с одного удара).
- [ ] Нокаут/падение без вылета игры.
- [ ] Смерть: без STR — как раньше; со STR — персонаж падает и встаёт (bleedout STR),
      **без загрузки сохранения**.

### 5. Только со Skyrim Together
- [ ] Двойника друга от STR не видно, пока рядом его персонаж Minecraft; без SkyCraft у друга
      двойник виден.
- [ ] Общие NPC: враг, которого бьёт один, получает урон и у другого.
- [ ] Квест/диалог у лидера группы продвигается у обоих.
- [ ] Отметьте подрагивание NPC возле блоков Minecraft (известная возможная проблема).

### 6. Стабильность
- [ ] Час игры без вылета у обоих; если вылет — время и действие.
- [ ] После выхода из игры в диспетчере задач нет `SkyCraftLink-*.exe`.

## Журналы после сессии

- Minecraft: `logs/latest.log` в папке Minecraft экземпляра (строки `SkyCraft Link:` — Steam).
- Skyrim: `Документы\My Games\Skyrim Special Edition\SKSE\SkyCraft.log` (+ `SkyCraft_crash.dmp`).
- STR: папка `logs` рядом с `SkyrimTogether.exe`.

SteamID в журнал Minecraft не пишется; просмотрите файлы перед передачей.

## Что уже проверено автоматически

Модульные тесты, два настоящих клиента Minecraft (LAN и через SkyCraft Link), заменители Skyrim
в разных локациях, хост на настоящем Steam. **В настоящем Skyrim, со STR и на двух ПК эта
сборка ещё не проверялась** — ради этого и нужна ваша сессия.
