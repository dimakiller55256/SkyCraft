# Пакет SkyCraft YS для друга

Сборка Java и изменённая SKSE DLL: `0.1.2-ys.network.6`, на основе
[официального SkyCraft 0.1.2](https://github.com/chasmlol/SkyCraft/releases/tag/v0.1.2).
Двери, фокус окна и падение требуют новой DLL: замены одного JAR недостаточно.
Native-часть собрана; её игровая приёмка описана в новой инструкции.
Пакет рассчитан на одинаковое проверенное окружение: Skyrim 1.7.104.0,
SKSE 2.3.1, Address Library для этого runtime, Minecraft 26.3, Fabric Loader
0.19.5, Fabric API 0.161.0+26.3, Java 25.

Для минимального ручного ввода используйте [новую игровую инструкцию](YS-GAMEPLAY.md):
SkyCraft-Хост.exe, SkyCraft-Клиент.exe и SkyCraft-Без-друга.exe из нового комплекта.

## Если исходный SkyCraft 0.1.2 уже работает

1. Распакуйте **весь внешний friend-kit ZIP** в отдельную папку вне Skyrim,
   например `D:\SkyCraftTest`. В MO2 не устанавливают внешний friend-kit:
   он содержит инструменты, таблицы и альтернативные архивы установки.
2. Закройте Skyrim и Minecraft SkyCraft. Запустите **«Установить обновление.cmd»**.
3. Откройте Prism → ПКМ на используемом экземпляре → **Папка Minecraft**.
   Скопируйте путь из проводника. Он должен содержать `mods`, `config`, `logs`.
   Это может быть `minecraft` либо `.minecraft`, а не корень Prism.
4. Введите этот путь в установщике. Затем выберите существующую SkyCraft.dll:
   MO2 слева → включённый SkyCraft → правой кнопкой → Открыть в проводнике →
   SKSE → Plugins → SkyCraft.dll. Он сверит новые JAR и DLL по SHA256, перенесёт
   активные старые SkyCraft/e4mc в `SkyCraft-YS-backups` рядом с экземпляром и
   установит новые SkyCraft JAR и DLL. Fabric API, конфиг, аккаунты и миры сохранятся.
   Для возврата: закрыть обе игры, убрать новый JAR, вернуть старые JAR и DLL из
   конкретной резервной папки. `installation.json` содержит исходные пути.
5. Запустите **«Проверить сборку.cmd»**: тот же каталог Minecraft, затем папку
   с `SkyrimSE.exe`, затем папку модов MO2. Последний путь берётся в
   MO2 → Настройки → Пути → Моды (Mods). Enter принимает показанный путь
   только если он верный. Итоговый ZIP в `reports` покажет версии, хеши, найденные
   SKSE/Address Library и подозрительные длинные пути внутри `Mods`.
   Наличие физической DLL не доказывает, что её
   мод включён: в MO2 должны быть включены SkyCraft и Address Library.
6. Запустите SKSE через MO2 как раньше. Загрузите отдельное тестовое сохранение
   после Хелгена, проверьте HUD, WASD и камеру. Нажмите **T** в Skyrim, в чате
   Minecraft введите `/skycraft debug status`. Основной сейв не перезаписывайте.
7. При проблеме: **«Собрать отчёт.cmd» → 1**, укажите каталог Minecraft и
   наблюдение. Программа соберёт последний автоматический JSONL запуска и
   сведения из native лога. На вопрос про полные логи ответьте `yes`, если
   готовы добавить `latest.log`, `SkyCraft.log` и логи SKSE; просмотрите их
   перед передачей. Аккаунты и конфиг с паролями не собираются.
8. Передайте `installation-*.zip` и `STARTUP-client-*.zip` из `reports`
   создателю сборки. Автоматической отправки нет.

## Если SkyCraft ещё не установлен

Установите Skyrim/SKSE/Address Library для проверенного runtime самостоятельно.
Они и игры в пакет не включены.

Внутри friend-kit есть **`SkyCraft-YS-…-MO2.zip`**. Установите **этот вложенный
архив** в MO2 как отдельный мод; отключите другую копию SkyCraft.dll. В нём
изменённая DLL network.6, общий `SkyCraft.ini` без чужих путей и подготовленный
Minecraft-комплект. С `sLauncher=` пустым SkyCraft распакует его в
`%LOCALAPPDATA%\SkyCraft` и запустит официальный portable Prism 11.1.1.
Первый запуск может потребовать входа в ваш Microsoft-аккаунт с Minecraft Java
и загрузки Minecraft/Java. Пользовательские аккаунты в архиве отсутствуют.

Если уже используется свой Prism, альтернативный путь — импорт вложенного
**`SkyCraft-YS-…-Prism-instance.zip`** через Prism → Добавить экземпляр →
[Импорт ZIP](https://prismlauncher.org/wiki/help-pages/zip-import/).
Затем в активном `SkyCraft.ini` укажите свой путь `sLauncher` и
`sArguments=--launch ИМЯ_ПАПКИ_ЭКЗЕМПЛЯРА`; имя папки берётся через ПКМ →
Папка экземпляра, это не всегда отображаемое имя. Установку из нового
MO2-архива с пустым `sLauncher` и свой лаунчер одновременно не используйте:
выберите один экземпляр, из него берутся `mods` и логи.

Существующая установка с собственным лаунчером обновляется первым способом;
заменять её рабочий INI общим INI из MO2-архива не требуется.

## Сетевой тест с владельцем

Все `join` и `network.*` находятся в **папка Minecraft из Prism → config →
skycraft.properties**. Как открыть файл, добавить отсутствующие строки,
задать пустое значение, сохранить и перезапустить игру — G1–G5 в инструкции.
В `SkyCraft.ini` эти параметры не вписываются.

Откройте **`docs/testing/ИНСТРУКЦИЯ.html`** браузером либо таблицу
**`docs/testing/SkyCraft-Network-Tests.xlsx`**. В одной LAN начните с L01,
в разных сетях — с I01/IPv6 I02. Раздел «Адрес хоста» показывает точный источник
IPv4, WAN/проброса и IPv6; произвольный IP из VPN не является приглашением.
В «Сценарии подробно» отфильтруйте ID: там команды и полный порядок теста.

Для сетевого отчёта **«Собрать отчёт.cmd» → 2**: совпадающий Run ID,
роль Host/Client, конкретные режимы и итог. Два ZIP с одним ID и заполненная
таблица нужны для сравнения сторон. Отчёт запуска в режиме 1 не заменяет
размеченный сетевой прогон.

## Если друга сейчас нет

Откройте **`ТЕСТЫ-БЕЗ-ДРУГА.html`** в корне распакованного комплекта.
Либо [YS-SOLO.md](YS-SOLO.md), либо вкладку **«Без друга»** в Excel.
Сначала G1–G8, затем B0–B10: локальный хост/TCP, отказ на закрытом порту,
отсутствующий SOCKS5 и HTTP-прокси, восстановление DIRECT и отдельные отчёты.
Для этих шагов готовые адреса и все поля сборщика указаны буквально.

Прототип не содержит NAT traversal/ретранслятора для двух закрытых сетей.
Для разных сетей хотя бы у одного ПК требуется доступный входящий TCP или
глобальный IPv6. Такую инфраструктуру нельзя гарантировать сборкой мода;
при её отсутствии сценарий отмечают BLOCKED. Совместные квесты STR и
конвертация предметов ещё не реализованы.
