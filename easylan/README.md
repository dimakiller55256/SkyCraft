# EasyLAN для Minecraft 26.3 — YS 1.6a-ys.26.3.1

Неофициальная адаптация [EasyLAN от XiaoXianHW](https://github.com/XiaoXianHW/EasyLAN)
для **Minecraft 26.3, Fabric Loader 0.19.5+, Java 25**. В комплекте Fabric API
0.161.0+26.3. Старый EasyLAN 1.21.x в Minecraft 26.3 не устанавливать одновременно
с этой версией. Мод работает и отдельно от SkyCraft.

## Установка в Prism

1. Закрыть Minecraft. Распаковать **весь ZIP** в отдельную папку вне Skyrim.
2. Prism → правая кнопка по нужному экземпляру **Minecraft 26.3 с Fabric** →
   **«Папка Minecraft»**. Скопировать путь из строки Проводника. Это каталог,
   содержащий `mods`, `config`, `logs`; не общая папка Prism и не папка `mods`.
3. В распакованном комплекте запустить **УСТАНОВИТЬ.cmd**, выбрать этот каталог.
   Установщик проверит контрольные суммы, перенесёт прежние EasyLAN/Fabric API
   в резервную копию и установит два JAR. Он сохраняет аккаунты, миры и настройки.
   При работающем Minecraft предлагает сначала закрыть его.
4. Запустить экземпляр. При выборе одиночных миров появится кнопка **EasyLAN**,
   внутри одиночного мира: **Esc → «EasyLAN: LAN»** в нижнем левом углу.
   Установка нужна хосту; клиенту она нужна для собственного меню и отчётов.

Ручная установка: при закрытом Minecraft перенести прежний EasyLAN и прежний
Fabric API из `mods` в отдельную резервную папку; скопировать **оба JAR** из
папки `mods` комплекта в `mods` экземпляра. Не хранить две версии одного мода
в `mods`. Fabric Loader устанавливается через «Изменить экземпляр → Версия →
Установить Fabric»; данный ZIP содержит моды, а не Minecraft или лаунчер.

## Хост — ваша частная игра с автономным профилем

1. Загрузить одиночный тестовый мир. Для первого теста у обоих включить Radmin,
   войти в **одну и ту же сеть Radmin**. Проверку сложных VPN начните после
   успешного контрольного подключения.
2. Нажать **Esc → EasyLAN: LAN**. Оставить **Порт TCP: 25565**, **Максимум
   игроков: 20**. Если 25565 занят, выбрать, например, 25570. Не подбирать
   случайный IP и не открывать LAN через другое меню раньше EasyLAN.
3. Нажать кнопку **«Проверка сессии: ONLINE»**, чтобы она стала **OFFLINE**.
   ONLINE проверяет текущую сессию Minecraft. OFFLINE позволяет вашему хосту
   принимать автономные профили, когда сессия не работает; имена игроков при
   этом не подтверждаются Microsoft. Эта настройка относится к вашему хосту.
4. Нажать **«Открыть LAN»**. Увидеть фактические порт и OFFLINE. Если LAN уже
   открыт с ONLINE, выйти в главное меню Minecraft, вновь загрузить мир и
   открыть через EasyLAN с OFFLINE. Смена режима действующего LAN не выполняется.
5. В открывшемся меню адреса определяются автоматически. Нажатие на строку
   адреса переключает адаптер. Для Radmin выбрать строку, где справа написано
   **Radmin VPN**; слева адрес вида `26.x.x.x:25565`. Нажать **«Копировать
   IP:порт»**, вставить в переписку с другом. Для общей домашней сети выбирать
   Ethernet/Wi-Fi, через который оба подключены к одному роутеру. **127.0.0.1
   / localhost годится только для второго клиента на этом же ПК.**
6. Если Windows покажет запрос брандмауэра для Java, разрешить доступ для
   используемой вами сети. EasyLAN не меняет брандмауэр, роутер или VPN.

## Клиент

1. Запустить **Minecraft 26.3**, выбрать свой профиль; имя должно отличаться
   от имени хоста. Войти в ту же сеть Radmin, что и хост.
2. Главное меню Minecraft → **«Сетевая игра» → «Прямое подключение»**. Вставить
   **целиком IP:порт, скопированный хостом**, например `26.x.x.x:25565`, и
   нажать **«Подключиться»**. `26.x.x.x` здесь обозначение, его вручную не вводят.
3. Хост подтверждает второго игрока; клиент проверяет движение и общие блоки.
   Если вновь «Недействительная сессия», хост проверяет фактический OFFLINE
   в меню и что клиент подключается к адресу именно этого хоста.
4. После результата оба открывают **Esc → EasyLAN: LAN → «Собрать отчёт ZIP»**.
   Путь к созданному ZIP попадёт в буфер обмена: вставить его в строку Проводника,
   найти файл и передать. При отказе до входа у клиента есть кнопка отчёта в
   главном меню/экране отключения. Для сборки без запуска игры есть
   **СОБРАТЬ-ОТЧЕТ.cmd** в комплекте — выбрать ту же папку Minecraft.

## Отчёты и настройки

Файл настроек: **`config\easylan.cfg` внутри выбранного каталога Minecraft**.
Меню сохраняет его само. Режим хранится в `online-mode=true` / `false`, порт
в `Port`, максимум игроков в `MaxPlayer`. Первое создание файла включает
ONLINE. После игры OFFLINE сохраняется для следующего открытия; для возврата
выбрать ONLINE перед открытием нового LAN. Повреждённое значение online-mode
не отключает проверку сессии автоматически.

Отчёты: **`easylan-reports` внутри каталога Minecraft**. ZIP содержит версии
модов/Java/Windows, локальные адреса адаптеров, фактический режим/порт/число
игроков, настройки EasyLAN и журнал его событий. Собираются события открытия,
ошибки входа и появления/выхода игроков. Аккаунты лаунчера, токены и полные
журналы игры не копируются. IP остаются в локальном отчёте; передавайте ZIP
лично. Каждый запуск имеет отдельный ID и журнал. HTTP API, если включён,
слушает только localhost; его данные не дают сетевую доступность сервера.

Дополнительные настройки: PvP, появление существ, полёт, MOTD, команды whitelist,
ban, op, save, вывод в чат, локальный HTTP API. Команды регистрируются при загрузке
мира: после их смены сохранить настройки и **перезайти в мир**. Чтобы применять
остальные правила последовательно, тоже закройте/вновь загрузите мир перед LAN.

## Проверка без друга

Автоматическая проверка разработчика запускает два настоящих Minecraft в
изолированных каталогах: ONLINE должен запросить авторизацию, затем через меню
включается OFFLINE и второй автономный клиент входит в мир. Хост должен увидеть
двух игроков. Это проверяет режим входа и меню, но не другой ПК или ваш VPN.

Для ручного повторения в Prism создать отдельный экземпляр 26.3 с Fabric и
скопировать только нужные моды; **не запускать один и тот же каталог мира двумя
процессами**. Первый экземпляр — хост по инструкции выше, второй — клиент с
другим именем. Адрес второго на этом ПК: **127.0.0.1:фактический_порт_хоста**.
Войти, поставить блок, подтвердить его у хоста. Собрать два отчёта. Локальный
успех не подтверждает соединение через Radmin/Cloudflare на другом ПК.

## SkyCraft

В SkyCraft окно Minecraft скрыто. Для ваших автоматических тестов удобнее
**SkyCraft network.5**: в **SkyCraft-Хост.exe** выбрать «Общая виртуальная сеть»,
DIRECT, поставить **«Хост: автономные профили (частная LAN/Radmin)»** до начала
теста. После перезапуска игры помощник сам откроет LAN с OFFLINE и выдаст SCY2.
Клиент вставляет новый SCY2 в **SkyCraft-Клиент.exe**. EasyLAN как дополнительный
JAR для этого сценария не обязателен: выбор входа делает сам SkyCraft network.5.
Не открывайте один и тот же LAN одновременно двумя средствами управления.

## Сборка и исходники

Полные исходники и Gradle wrapper находятся в `sources.zip`. JDK 25; кеш Gradle
должен быть **вне каталога Skyrim**. Из папки исходников: `gradlew.bat build`.
В репозитории: `easylan\gradlew.bat -p easylan build`. Интеграционный тест:
`tools\test-easylan.ps1` (локальные пути JDK/кеша — `.tools/dev-local.json`).
Тестовый мод исключён из распространяемого JAR.

Основа: EasyLAN 1.6a, ветка fabric/1.20.6-1.21.11, commit
`6e3effad7a76bddb49ac901560683300325765f0`. Лицензия **GPL-3.0-only**, авторство
оригинала сохранено. Изменения: API экранов/правил 26.3, отдельное меню LAN,
единый реальный порт, выбор проверки сессии до открытия, отчёты и тесты.
NAT traversal/ретранслятор и обработка системного прокси здесь не добавлены.
