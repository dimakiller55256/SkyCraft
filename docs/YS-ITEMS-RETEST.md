# Повтор конвертации без друга — network.11-r13

В отчёте от 11 октября пять обменов отменились до удаления оригинала: железо, золото, яблоко, меч и том «Пламя». Minecraft подтвердил подготовку. Причина найдена в коде Skyrim: поиск через общий базовый тип ошибочно проверял один конкретный тип формы и возвращал пустой результат. r13 использует корректное преобразование типа после поиска по файлу и локальному ID. Причины отмен теперь записываются в журнал.

Сохранение через меню в предыдущем тесте работало — снимки SKSE есть в отчёте. Указание F5 было ошибкой инструкции: эта клавиша переключает камеру Minecraft. Новые подсказки и шаги используют меню Skyrim. Ошибки автономного аккаунта при обращении к Realms не были причиной этих пяти отмен.

## Что подготовить

Нужен комплект **SkyCraft-AutoTests-0.1.2-ys.network.11-r13**. Старый помощник r12 для нового теста не используйте. На этом ПК разработчик устанавливает обновление при закрытых играх; если сообщил об установленном r13, повторно обновлять не требуется.

На другом ПК: распаковать **весь ZIP**, например в `C:\SkyCraftTests\items-r13`; EXE из окна архива не запускать. При закрытых Skyrim и Minecraft открыть `SkyCraft-Без-друга.exe` → **Обновить мод**. Папка Minecraft содержит `mods`, `config`, `saves`; у вас это `D:\PrismLauncher\instances\SkyCraft\minecraft`. DLL выбирается в MO2: слева SkyCraft → правая кнопка → Открыть в проводнике → SKSE → Plugins → **SkyCraft.dll**. Установщик делает резервную копию.

Не удаляйте журналы и не исправляйте старый тестовый инвентарь командами. Начните новый прогон ниже. Основное сохранение Skyrim не заменяйте.

## Короткая проверка: три команды и загрузка

1. Запустите **SKSE через MO2**. Загрузите отдельное обычное сохранение после Хелгена. Перейдите на ровное безопасное место без боя. Пока ничего не подбирайте.

2. Откройте **SkyCraft-Без-друга.exe из нового комплекта**. Нажмите **Тест предметов без друга**. Дождитесь подтверждения отдельного мира и журнала. Alt+Tab вернитесь в Skyrim. Помощник открывает Minecraft-мир `SkyCraft-Items-Test`; обычный мир для этого обмена не используется.

3. В меню **Skyrim**: Esc → Сохранить → **Новое сохранение**. Дождитесь окончания записи и закройте меню. Это включает обмен для нового тестового профиля. **F5 не нажимайте.** Предметы, поступившие до этого сохранения, автоматически не конвертируются.

4. **E** открывает инвентарь Minecraft. Освободите не меньше трёх обычных ячеек, запомните число железных слитков, закройте E. Консоль **Skyrim** открывается клавишей `~`/`Ё` под Esc; раскладка английская. Выполните строки таблицы **по одной**: ввести → Enter → закрыть консоль той же клавишей → ждать до пяти секунд → E и сверить результат → закрыть E. Не вводите строки в чат Minecraft, который открывается T.

| Строка в консоли Skyrim | Ожидаемый прирост в Minecraft |
|---|---|
| `player.additem 0005ACE4 3` | Ровно 3 железных слитка сверх прежнего количества |
| `player.additem 0009CD51 1` | Одна зачарованная книга: **Заговор огня I** в подсказке при наведении |
| `player.additem 0002F839 1` | Одна книга с двумя чарами: **Прочность II + Починка I** |

Если первая команда не выдала предметы, **не продолжайте** остальные проверки: в помощнике «Конвертация → Ошибка», в поле «Что произошло» — «После player.additem 0005ACE4 3 слитки не добавились». Нажмите **Остановить и собрать отчёт**. Журнал теперь покажет конкретную причину отмены. «Предметы на полу» и «Предметы: загрузка» оставьте **Не проверено**, если до них не дошли.

5. Если три команды прошли: «Конвертация → Работает». В Skyrim **Esc → Сохранить → Новое сохранение**, дождитесь записи. Затем **Esc → Загрузить → именно только что созданное сохранение**. Игры и помощник между этими действиями не закрывайте; кнопку «Тест предметов без друга» второй раз не нажимайте. После появления HUD нажмите E: количество и чары должны остаться прежними, без удвоения. Отметьте **Предметы: загрузка → Работает/Ошибка**.

6. Нажмите **Остановить и собрать отчёт** → **Открыть отчёты**. ZIP текущего запуска содержит логи обоих модов и журналы обменов; передайте ZIP в этот чат. После сбора закройте Skyrim через его меню и дождитесь завершения Minecraft. Для обычной игры позже загрузите обычное Skyrim-сохранение, а не созданный здесь тестовый профиль.

## Что пока пропустить

Для первого повторного теста не нужны друг, поиск IP, заполнение всего инвентаря и размещение предмета на земле. Невидимый слиток после команды размещения — отдельное наблюдение: отчёт не устанавливает его причину. Создание предмета у игрока — **`player.placeatme`**, выдача в сумку — **`player.additem`**. Сначала проверяем обмен через выдачу в сумку.

Если короткий тест прошёл, необязательное переполнение и физический подбор описаны в [полной инструкции](КОНВЕРТАЦИЯ-ПРЕДМЕТОВ.html). Надетые, отмеченные в избранном или иначе защищённые экземпляры могут остаться в Skyrim — причина будет в логе. Все источники зачарованных книг — в [инструкции по книгам](КНИГИ-ЗАЧАРОВАНИЙ.html).

## Что подтверждают проверки разработчика

Регрессионная C++-проверка воспроизводит отказ прежнего поиска и проверяет используемую модом функцию для типов предмета, оружия, брони и книги, а также неправильного файла/ID и неподходящего объекта. Это проверка кода без запущенного Skyrim. Сборка и Minecraft-тесты отдельно не доказывают фактическое удаление предмета и сохранение в Skyrim: это проверяют шаги 4–5.
