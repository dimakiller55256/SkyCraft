# Конвертация предметов — network.9-r11

Первая версия автоматически обменивает **новые поступления** в инвентарь Skyrim по таблице из 565 соответствий: ресурсы, слитки, монеты, камни, шкуры, строительные материалы, еда, часть ингредиентов и зелий, обычное оружие, броня, одежда, украшения, камни душ, инструменты, стрелы, факелы, посуда и обычные книги. Исходный предмет удаляется только после того, как Minecraft подтвердил, что понимает замену. Предметы, лежавшие в инвентаре до включения обмена, автоматически не перебираются.

По умолчанию **1 предмет Skyrim → 1 предмет Minecraft**. Аналоги приближены: сталь → железо; серебро → железо; двемерский металл → золото; перчатки → поножи; сыр → хлеб; обычная книга → пустая книга. Монеты Skyrim становятся золотыми самородками и перестают быть деньгами для торговцев Skyrim. Таблица `ТАБЛИЦА-ПРЕДМЕТОВ.html` показывает все замены. Заклинания, квестовая механика и текст книг не переносятся.

Неизвестные предметы, ключи, квестовые, зачарованные, краденые/помеченные владельцем, отравленные, улучшенные, переименованные, надетые и добавленные в избранное вещи остаются в Skyrim. Защита консервативная: если у одного типа предмета есть защищённый экземпляр, новый экземпляр того же типа тоже может остаться. Модификации Skyrim не угадываются по названию; их можно добавить в таблицу явно.

Если места нет, Minecraft выдаёт остаток **перед игроком у поверхности**. На земле отображается один стак, следующий появляется после подбора. Эти предметы до подбора доступны владельцу, не исчезают по таймеру и сохраняются в журнале его инвентаря. Воронки и существа Minecraft не забирают неподобранный остаток. Он удерживается у места выдачи без падения в пустоту Minecraft; редкие провалы самого персонажа этим не исправлены. После подбора предмет обычный: его можно использовать, выбрасывать и передавать другу.

## Проверка без друга: 5–10 минут

1. Распакуйте **весь** архив `SkyCraft-AutoTests-0.1.2-ys.network.9-r11.zip` вне Skyrim, например в `C:\SkyCraftTests\items-r11`. EXE внутри ZIP не запускайте. При закрытых играх откройте `SkyCraft-Без-друга.exe` → **Обновить мод**. Minecraft: `D:\PrismLauncher\instances\SkyCraft\minecraft`. Установленная DLL: MO2 → слева SkyCraft → правой кнопкой → Открыть в проводнике → `SKSE\Plugins\SkyCraft.dll`. Укажите этот существующий файл, который нужно заменить.
2. Запустите SKSE через MO2. Загрузите отдельное сохранение после Хелгена. Пока ничего не подбирайте. В помощнике нажмите **Тест предметов без друга**, затем вернитесь Alt+Tab в Skyrim и дождитесь сообщения о готовности в помощнике. Он открывает отдельный Minecraft-мир **SkyCraft-Items-Test** и создаёт отдельный тестовый журнал обменов. Обычный Minecraft-мир не используется для этих обменов.
3. В Skyrim нажмите Esc → Сохранить → **Новое сохранение**. Это первый тестовый снимок; основное сохранение не заменяйте. Подождите окончания сохранения. Надпись о необходимости сохранения должна исчезнуть. До первого снимка обмен выключен: ранее подобранные предметы останутся в Skyrim.
4. Откройте консоль **Skyrim** клавишей `~`/`Ё` (под Esc); переключите раскладку на английскую. Введите строку `player.additem 0005ACE4 3`, нажмите Enter, закройте консоль той же клавишей и подождите до пяти секунд. Это три железных слитка. Нажмите **E**, чтобы открыть инвентарь Minecraft: должно добавиться **3 железных слитка**. Закройте E. В инвентаре Skyrim их не должно прибавиться на три. Команда используется только на тестовом сохранении; она проверяет поступление, а не физическую кнопку подбора.
5. Повторите шаг 4 для каждой строки ниже, каждый раз закрывая консоль и ожидая пять секунд. Количество Minecraft сравнивайте **до и после**, потому что похожие вещи могли уже быть в стартовом наборе.

| Ввести в консоль Skyrim | Что должно добавиться в Minecraft |
|---|---|
| `player.additem 0005AD9E 2` | 2 золотых слитка |
| `player.additem 00064B2E 1` | 1 яблоко |
| `player.additem 00012EB7 1` | 1 железный меч |
| `player.additem 00012E4D 1` | 1 железный шлем |
| `player.additem 00093B08 1` | Ничего: ключ от Дома тёплых ветров остаётся в Skyrim |

6. Для физического подбора в консоли Skyrim введите `player.placeatme 0005ACE4 1`, Enter, закройте консоль. Найдите появившийся слиток у ног, наведитесь и нажмите **G** (подбор Skyrim). Должен добавиться ещё один железный слиток Minecraft. Предметы из контейнеров также обрабатываются при поступлении в инвентарь; отдельно возьмите знакомую еду из незапертого доступного контейнера, если он рядом. Кражу для этого теста не делайте.
7. Отметьте **Конвертация → Работает/Ошибка** в помощнике. В поле «Что произошло» напишите только расхождения: команда, сколько было/стало, что осталось в Skyrim. После выдачи предметов появляется просьба сохранить Skyrim. Нажмите F5 и дождитесь окончания сохранения.
8. В рамках того же запуска и того же тестового мира загрузите **только что сделанное** быстрое сохранение. Подождите HUD, откройте E: предметы должны остаться, количество не должно удвоиться. Отметьте **Предметы: загрузка**. Затем один раз повторите команду слитка: это новая выдача, она должна добавить ровно указанное количество. Снова F5.
9. Нажмите **Остановить и собрать отчёт**, укажите оценки; после остановки оценки автоматически обновляют ZIP. **Открыть отчёты** открывает папку ZIP. В отчёт входят игровые логи и свежие журналы обменов. Передайте ZIP сюда; не загружайте журналы на публичный GitHub. Закройте Skyrim через меню и дождитесь закрытия Minecraft. На следующем обычном запуске загружайте обычное сохранение Skyrim, а не сохранение тестового профиля.

Для этой первой ручной проверки достаточно пунктов 1–9. Полный инвентарь, выдача 65 предметов, повторные запросы, запись/чтение квитанций и реальный обмен сетевыми пакетами проверяются отдельно автоматическим тестом разработчика. Игровой тест Minecraft не подтверждает правильность SKSE-подбора на вашем Skyrim: это проверяют пункты 4–8.

## Переполнение — необязательная ручная проверка

Выполняйте только в отдельном мире из кнопки **Тест предметов без друга**.

1. E: убедитесь, что есть место, запомните количество железных слитков. E: закройте инвентарь. T открывает чат **Minecraft**, `~` — консоль Skyrim; не путайте их.
2. В чате Minecraft вводите `/give @s minecraft:cobblestone 2304`, Enter. Команда доступна, потому что отдельный мир создан с командами. Она заполняет свободные места булыжником; лишнее само падает у игрока. E: убедитесь, что все 36 ячеек нижнего инвентаря заняты; ячейки брони не считаются. При необходимости повторите команду. Если остался неполный стак железа, заполните его через `/give @s minecraft:iron_ingot 64` и снова проверите E. Другие неполные стаки не мешают проверке железа.
3. В консоли Skyrim: `player.additem 0005ACE4 65`, Enter, закройте консоль. Перед вами должны появиться слитки. Если все места заняты, наступание на слитки не должно их уничтожить.
4. E: выберите стак булыжника, перетащите за край окна инвентаря, отпустите кнопку мыши. E: закройте окно. Пройдите на слитки: должно подобраться 64. Освободите ещё одну ячейку и подберите оставшийся 1 (следующий стак появляется в течение секунды). Проверьте прирост ровно **65**. Отметьте **Предметы на полу**, затем F5.

## Когда обмен останавливается

Обмена между двумя отдельными сохранениями нельзя сделать полностью атомарным при любом аварийном завершении или ручном откате одного из миров. Эта версия ведёт журнал, не повторяет подтверждённые запросы и останавливает обмен при расхождении Skyrim-сохранения с журналом, прерванном удалении или смене Minecraft-мира/владельца во время обмена. Незавершённый обмен после обычного обрыва повторяется с тем же ID; Minecraft не выдаёт его второй раз.

Если видите **Обмен остановлен**, больше предметы не подбирайте для обмена. Соберите отчёт. После обычной загрузки более старого сохранения попробуйте загрузить последнее сохранение, сделанное **после** выдачи. Не удаляйте журналы, не переименовывайте профиль Minecraft и не добавляйте потерянные предметы командами до разбора отчёта. Такой остановленный обмен не означает вылет Skyrim; обычная игра может продолжать работать. При смене на другого персонажа без первого снимка обычного обмена также может потребоваться разбор журнала.

Первая версия хранит до 8192 обменов на профиль Minecraft и на профиль Skyrim. При достижении предела новые предметы остаются в Skyrim; потребуется обновление для продолжения обмена. Журнал не очищается автоматически, потому что старые квитанции нужны для защиты от повторной выдачи.

Тестовый профиль помечен отдельно: его история не блокирует исходное обычное сохранение. В обычном Minecraft-мире сохранение с тестовым профилем не конвертирует предметы — нужно загрузить обычное Skyrim-сохранение. Если закрыли игры и запускаете тест заново, кнопка создаёт новый тестовый профиль; это новый прогон, а не проверка восстановления предыдущего обмена.

Для резервных копий обычной игры сохраняйте согласованный комплект: `.ess` **и соответствующий `.skse`**, папку Minecraft-мира (`saves\SkyCraft`) и папку журналов ниже. Произвольное восстановление только одного файла не восстанавливает согласованное состояние обоих инвентарей. Запись на диск проверяется; отказ записи останавливает выдачу/вызывает повтор. Это не обещание защиты от потери диска или любой ошибки файловой системы.

## Где находятся настройки и журналы

При обновлении помощник помещает таблицу рядом с **выбранной установленной** DLL: MO2 → слева SkyCraft → Открыть в проводнике → `SKSE\Plugins\SkyCraft-items.json`. Для вашей установки полный путь: `D:\The Elder Scrolls V - Skyrim\Mods\SkyCraft\SKSE\Plugins\SkyCraft-items.json`. Если ставите DLL вручную без помощника, мод создаёт отсутствующую таблицу при первом запуске. Файл из комплекта `item-conversion-default.json` — образец; его редактирование не меняет установленную таблицу. Обновление DLL не перезаписывает существующую таблицу.

Закройте обе игры, сделайте копию установленного JSON, откройте его в редакторе. `enabled: false` выключает конвертацию. Строка `items` содержит `plugin` (имя ESP/ESM/ESL), `form` (локальный FormID в шестнадцатеричной записи **без индекса загрузки**), `minecraft` (ID замены), `count` (целое число 1–64 на один исходный предмет). `editor` и `category` — пояснения. Для зелий используется, например, `minecraft:potion#healing`. Для изменения перезапустите обе игры. Неизвестная Minecraft-замена отклоняется до удаления предмета Skyrim. Ошибка JSON выключает конвертацию с записью в лог. Чтобы оставить монеты Skyrim, удалите строку с `editor: Gold001` из `items`, сохранив корректные запятые JSON.

Журналы Skyrim: **Документы → My Games → Skyrim Special Edition → SKSE → SkyCraft-items**, отдельный JSON на профиль. Последние операции также видны в `SkyCraft.log` в родительской папке. Не редактируйте JSON журналов вручную. Minecraft хранит квитанции и неподобранные остатки в данных игрока вместе с инвентарём; идентификатор мира — `saves\SkyCraft\skycraft-item-world.txt` (у тестового мира: `saves\SkyCraft-Items-Test`). После выхода эти папки можно копировать для согласованного резервного снимка.
