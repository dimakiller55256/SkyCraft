# Проверки конвертации network.9-r11

10.10.2026. Базовая установленная версия перед изменением: network.8-r10; Skyrim AE 1.7.104.0, SKSE 2.3.1, Minecraft 26.3, Java 25. Сетевые, клавиатурные и боевые исправления сохранены. Редкие провалы остаются известной проблемой и не являются целью этого изменения. Skyrim Together Reborn пока не интегрирован.

В таблице **565 соответствий** из локально прочитанных EditorID/FormID Skyrim.esm, Dawnguard.esm, HearthFires.esm и Dragonborn.esm. Таблица содержит идентификаторы, без копирования игровых ресурсов. Это выбранные приближённые аналоги, а не конвертация каждого предмета любой модификации Skyrim. Неизвестные предметы остаются в Skyrim.

Автоматические проверки:

- Gradle: сборка обеих Java-частей и **92 теста**, в том числе квитанции после повторной загрузки, изменённый запрос с прежним ID, неверные количества, повреждённое переполнение и разбиение длинного журнала без потери символов.
- SKSE: сборка C++ плагина на настроенном VS 2026, аудит известных отсутствующих AE-релокаций. Ненулевой адрес не является доказательством правильности функции на реальном Skyrim.
- Исполняемый C++ тест политики восстановления: подтверждённое удаление возобновляется; откат Skyrim-сохранения или внешнего журнала, повторные ID и прерванное удаление отклоняются.
- Два настоящих Minecraft-клиента в удаляемом тестовом мире: LAN/PLAY, сетевые запросы конвертации клиента и ответы сервера; полная таблица проверена по реестру Minecraft 26.3.
- Реальный сервер: полный инвентарь и выдача **65 слитков** через журнал остатка; подбор 64 + 1, сохранение квитанций в том же NBT, что инвентарь; чтение с диска; пересоздание отображаемого предмета после чтения журнала; повторный commit не удваивает выдачу. Чужой игрок и воронка не забирают остаток владельца; хост не получает выдачу клиента. Для существ выставлен запрет обычного подбора. Неизвестный предмет, изменённый запрос и неверный владелец отвергаются. Журнал с 1000 дополнительными квитанциями, превышающий 64 КиБ, записан и прочитан без потери записей.
- Повторное открытие отдельного мира **SkyCraft-Items-Test** проверено настоящим Minecraft. Подтверждение отдельного профиля SKSE выполняется помощником через локальную общую память; игровая проверка этой части требует Skyrim.

Чтение сохранённой квитанции и пересоздание предмета в тесте моделируют восстановление после обычного перезапуска; это не эксперимент с принудительным отключением питания. Временный файл игрока записывается и сбрасывается на диск до атомарной замены. Ошибки сохранения возвращают повтор/остановку; журнал не обещает атомарного сохранения двух разных игр или защиты от потери носителя. При откате Skyrim после обмена включается карантин, который сохраняется даже при сохранении остановленного профиля. Для копий нужен согласованный набор `.ess`, `.skse`, Minecraft-мир и журналы.

На момент сборки **не подтверждены в Skyrim**: физический подбор G, события контейнера, фактическое удаление/защита предметов, создание отдельного тестового профиля, сохранение/загрузка инвентаря и показ переполнения поверх Skyrim. Для этого предназначены пункты 1–9 инструкции **YS-ITEMS.md**. Успешная сборка и Minecraft-тесты не заменяют эти проверки. Соединение между двумя физическими ПК также ждёт друга.

Подробные локальные логи и результаты находятся в игнорируемом `dist/review-20261010-r11`; их не публикуют на GitHub. Установщик сохраняет старые JAR/DLL и не заменяет существующие миры, настройки, аккаунты или пользовательскую таблицу.

При сборке под нагрузкой существующий сетевой тест передачи 1 МиБ дважды получил таймаут 5 секунд. Последний полный запуск 92 тестов прошёл. Это нестабильность проверки, которую не скрывают повтором; сетевой код и таймаут ради этой сборки не менялись. Полный игровой прогон также прошёл. Проверка открытия уже созданного тестового мира сначала обнаружила скрытый запрос резервной копии: он устранён для `SkyCraft-Items-Test`, повторный прогон прошёл.
