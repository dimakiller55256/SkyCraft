# Второй прогон SkyCraft — network.6

**Актуальный комплект: r7. Старую DLL r6 не устанавливать: она вызывает вылет AE при загрузке сохранения.** Сначала выполнить инструкцию ИСПРАВЛЕНИЕ-ЗАГРУЗКИ.html из нового комплекта.

Обновить **оба ПК до 0.1.2-ys.network.6**. Обновляются JAR и SkyCraft.dll. Игровая инструкция: ИГРОВЫЕ-ПРОВЕРКИ.html. Добавлен явный режим
входа автономных профилей у хоста; сохраняются ввод движения и все этапы ожидания
готового мира. Помощник разделяет TCP, вход
Minecraft и восстановление; проверяет реальный прокси, версию и ID хоста;
собирает среду до/после. Python, SDK и дополнительный аккаунт не нужны.

## Подготовка — один раз на каждом ПК

1. Распаковать **весь SkyCraft-AutoTests-0.1.2-ys.network.6-r7.zip** в отдельную папку
   вне Skyrim, например `D:\SkyCraftTests5`. EXE из окна архиватора не запускать.
   Старый комплект network.3 с отчётами сохранить.
2. Открыть **SkyCraft-Без-друга.exe**. Все три EXE — одинаковая программа, имя выбирает
   начальную роль. Поле **Minecraft** должно содержать каталог с `mods`, `config`,
   `logs`. У хоста: `D:\PrismLauncher\instances\SkyCraft\minecraft`.
   У друга путь может быть другим. Узнать свой: Prism → правая кнопка по используемому
   экземпляру SkyCraft → «Папка Minecraft» → скопировать путь из строки Проводника.
   Вставить его в поле помощника или выбрать кнопкой «Выбрать папку».
3. Закрыть Skyrim через меню, дождаться закрытия связанного Minecraft. Нажать
   **«Обновить мод»**, дождаться сообщения об установленном обновлении. При отказе
   прочитать сообщение: Skyrim и выбранный Minecraft должны быть закрыты.
   При запросе выбрать существующую SkyCraft.dll: MO2 слева → SkyCraft → правой кнопкой → Открыть в проводнике → SKSE → Plugins. Старые DLL и JAR сохраняются в `SkyCraft-YS-backups` рядом с экземпляром; аккаунты,
   миры и `config\skycraft.properties` сохраняются. Работающий процесс получает
   новый мод только после перезапуска, а не после одной замены файла.
4. Поле **Skyrim** — каталог с `SkyrimSE.exe`. Поле **Моды MO2** — общий каталог
   папок модов. Узнать его: MO2 → настройки → «Пути» → «Моды» / Mod directory.
   У хоста это `D:\The Elder Scrolls V - Skyrim\Mods`. Кнопка «Выбрать моды»
   исправляет путь. Это не папка одного SkyCraft. Неизвестный путь оставьте пустым:
   установочный отчёт отметит непроверенные файлы; сетевые тесты продолжатся.
5. Запустить **MO2 → SKSE**, загрузить **отдельное тестовое сохранение после Хелгена**.
   Главного меню недостаточно. Дождаться HUD Minecraft и движения, встать на
   устойчивой поверхности. Не сохранять поверх основного сохранения.
6. Alt+Tab в помощник. Properties для этого сценария **не редактировать**.
   Транспорт задаётся временно списком «Транспорт», снимается после теста или
   максимум через 15 секунд после аварийного закрытия помощника.

**Для вашей ошибки «Недействительная сессия»:** у хоста в окне программы поставить
галочку **«Хост: автономные профили (частная LAN/Radmin)»** и выбрать **«Общая
виртуальная сеть»** (для Radmin) либо **«Одна локальная сеть»** (для общей домашней
сети). У клиента режим придёт в новом коде хоста; конфигурационные файлы вручную
не нужны. Перед первым запуском с этой галочкой перезапустить Skyrim/Minecraft:
у уже открытого LAN режим входа может остаться ONLINE. `HOST_AUTHENTICATION PASS`
должен содержать **OFFLINE**. Наличие лицензии не меняет эту диагностику: отказ
был проверкой текущей сессии. В OFFLINE сервер не подтверждает принадлежность
имени Microsoft; для этой проверки используйте вашу частную сеть игроков.

Режим сохраняется до закрытия мира. После теста для возврата к ONLINE закрыть
Skyrim/Minecraft, убрать галочку у хоста и начать новый прогон. Отдельный мод
EasyLAN для обычного Minecraft имеет собственное меню; для автотеста скрытого
Minecraft в SkyCraft эту же настройку выполняет помощник.

## Без друга — примерно 1–3 минуты

1. Открыть **SkyCraft-Без-друга.exe**, роль **«Без друга»**, транспорт **DIRECT**.
   Большое поле кода пустое. Поле «Прокси» выключено. «Сеть» в этом сценарии
   не используется: проверяется только этот ПК.
2. В **«Условия / имя теста»** написать, например:
   `R2-SOLO; zapret ALT on; Cloudflare off; VPN off`.
   Указать фактическое состояние. Запущенный процесс ещё не означает подключённый VPN.
   Ваша подпись условий сохраняется отдельно от автоматических технических снимков.
3. Нажать **«Начать автотест»**. **Не двигаться до окончания**. Помощник сам проверяет
   реальные сокеты, открывает собственный сервер, выбирает закрытый локальный порт,
   пытается войти и восстанавливает мир. Цикл повторяется **три раза**.
   Вручную /join, /leave, IP и команды вводить не надо. В мире не должно быть других игроков.
4. После каждого восстановления программа 5 секунд измеряет позицию Skyrim.
   Максимальное смещение от позиции до перехода должно быть не больше **3 блоков**:
   допуск учитывает штатный подъём из геометрии до 2,5 блока. Это проверка крупного
   сброса/падения; движение игрока делает её результат неоднозначным. Если двигались,
   подпишите это и повторите неподвижно.
5. При падении, телепортации или пропаже HUD выбрать **«Ошибка»** в соответствующем
   списке HUD/Движение и нажать **«Остановить и собрать отчёт»**. Повторно падать ради
   логов не требуется. При обнаружении неверного восстановления программа сама
   прекращает дальнейшие переходы и собирает отчёт.
6. Дождаться **«Готово: ...zip»**, нажать **«Открыть отчёты»**. Передать внешний ZIP,
   имя которого совпадает с папкой прогона. ИТОГИ.txt внутри читается обычным Блокнотом.

Локальный PASS не подтверждает доступ через Интернет или двух игроков.

## Парный повтор — Radmin + DIRECT

Это повтор пути, где ранее TCP был доступен, но вход Minecraft обрывался.
Оба игрока должны уже состоять **в одной сети Radmin VPN** и видеть друг друга
подключёнными в Radmin. Помощник Radmin не устанавливает.

1. На обоих ПК выполнить подготовку, загрузить тестовые сохранения. В Prism
   использовать разные имена игроков. Режим авторизации не менять по догадке:
   сначала новый лог покажет настоящую причину отказа.
2. Для **R2-01** оставить прежний **zapret ALT на хосте**, с которым был Radmin-тест.
   Cloudflare и дополнительный VPN на обоих отключить; Radmin включён.
   На клиенте zapret отключён. Если эти условия недоступны, записать фактические.
3. **Хост:** открыть **SkyCraft-Хост.exe**. Роль «Хост», сеть «Общая виртуальная сеть»,
   транспорт **DIRECT**, поле кода пустое. В условиях:
   `R2-01; HOST; Radmin; zapret ALT on; Cloudflare off; VPN off`.
   Нажать **«Начать автотест»**, дождаться HOST_OPEN и HOST_LOCAL_TCP.
4. **Хост:** нажать **«Копировать код хоста»**, передать **весь новый SCY2-код** другу.
   IP, порт и ID уже внутри. Самостоятельно искать адрес или сообщать отдельный
   порт не нужно. Старый код SCY1 непригоден. Помощник хоста остаётся работающим.
5. **Клиент:** открыть **SkyCraft-Клиент.exe**. Роль «Клиент», сеть
   **«Общая виртуальная сеть»**, транспорт **DIRECT**. Вставить новый полный код
   в большое многострочное поле. Поле «Прокси» выключено. В условиях:
   `R2-01; CLIENT; Radmin; zapret off; Cloudflare off; VPN off`.
   Нажать **«Начать автотест»**.
6. Программа выберет только виртуальные адреса, сначала **Radmin IPv4**.
   WARP и произвольный WireGuard не объявляются общей сетью игроков.
   В этом режиме публичные IP и физическая LAN не перебираются; после TCP
   проверяются вход Minecraft, версия network.6 и ID текущего прогона хоста.
7. **При отказе:** клиент сохраняет причину, фазу и восстановление своей позиции.
   Дождаться его ZIP. Затем хост нажимает **«Остановить и собрать отчёт»**, не ожидая
   20 минут. Передать **оба ZIP**. Не менять вслепую прокси, проброс порта или
   авторизацию: сначала разбираем эту пару логов.
8. **При успешном входе:** оба Alt+Tab в игру. Клиент записывает **180 секунд**,
   хост — **240 секунд** с появления второго игрока. Дополнительное время хоста
   нужно для выхода, восстановления и повторного входа клиента. Игры и помощники не закрывать.
9. **0–60 секунд:** проверить HUD. **60–120 секунд:** пройти вперёд/назад, повернуться
   и остановиться на земле. **120–180 секунд:** поставить имеющийся блок; второй
   подтверждает появление. Сломать блок; второй подтверждает исчезновение.
   Если блока нет, оставить «Не проверено». В помощнике на каждом ПК выбрать
   для HUD/Движение/Блоки **«Работает»**, **«Ошибка»** или **«Не проверено»**.
   Программа сохраняет это как наблюдения человека, а не выводит из TCP PASS.
10. **К концу 180 секунд клиент должен стоять неподвижно.** Программа сама вернёт
    его в собственный мир, измерит позицию и повторно войдёт на хост. На ожидание
    каждого мира даётся до 90 секунд. После повторного входа — ещё 15 секунд наблюдения.
    В это время не загружать другие сохранения.
11. Дождаться ZIP на обоих ПК, нажать **«Открыть отчёты»**. Клиент остаётся у хоста.
    Позже вернуться: T → написать `/leave` → Enter. Хост остаётся в своём опубликованном мире.

**Для каждого прогона новый код.** SCY2 действует 30 минут; принимающий сервер
сообщает текущий ID. Старый код к новому или завершённому тесту даст SESSION_MISMATCH.
Код содержит тестовые адреса; это не пароль и не средство авторизации.

## Следующие комбинации — один новый фактор за прогон

Переходить к ним после успешного R2-01 либо анализа его конкретного отказа.
Перед новой строкой завершить оба помощника кнопкой сбора отчёта. Клиенту,
оставшемуся у хоста, вернуться `/leave`, встать на месте. Выставить условия,
начать **новый прогон хоста**, передать **новый код**, начать клиента.
Radmin и DIRECT сохраняются, если не указано иначе.

**R2-02:** контроль, оба без zapret/Cloudflare/дополнительного VPN; Radmin включён.

**R2-03:** хост zapret ALT + Cloudflare «трафик и DNS» с вашим UDP-профилем,
клиент чистый. Подключение включить переключателем в своём Cloudflare One Client.
Status/settings попадут в отчёт; Disconnected не считается подключённым WARP.

**R2-04:** поменять роли — сложная комбинация у клиента, чистый хост. Это проверяет
другой, исходящий путь. Роли EXE/списков поменять, первым снова стартует хост.

**R2-05:** zapret + Cloudflare + ваш VPN в режиме туннеля на обоих.
Указать название/режим VPN в условиях. DIRECT идёт по маршрутам Windows и не
отключает WARP/VPN. selectedRoutes покажет выбранный интерфейс к адресам хоста.

**R2-06:** VPN клиента в режиме **системного прокси**, без его VPN-туннеля;
хост в ранее успешных условиях. В приложении VPN найти реально включённый SOCKS5
или HTTP-порт. В помощнике клиента выбрать SOCKS5 либо HTTP_CONNECT и в поле
«Прокси» вписать **адрес прокси на ПК клиента**, например `127.0.0.1:1080`,
**только если приложение действительно указывает 1080**. Порт взять из настроек
своего приложения, не из этого примера. Это не адрес хоста и не порт Minecraft.
Если порт неизвестен — этот сценарий пока не выполнять, записать «порт не найден».

Порт системного прокси может быть подсказан из Windows, но его доступность
проверяется отдельно. PROXY_PREFLIGHT PASS означает лишь слушающий TCP-порт;
SOCKS5/CONNECT и доступ к целевому адресу проверяются затем. PROXY_UNAVAILABLE
означает отказ прокси **до проверки хоста**. Прокси может запрещать частные/Radmin
адреса. PAC и системный прокси не применяются автоматически к Java.
Логин/пароль берутся из прежних properties только для того же адреса и не записываются в отчёт.

Cloudflare **Local proxy** отличается от «трафик и DNS». Использовать только
действительно настроенный Local proxy и его порт. 40000 — стандартное значение,
которое может быть изменено, а не доказательство наличия прокси на ПК.
[Официальные режимы One Client](https://developers.cloudflare.com/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/modes/).

## Интернет без Radmin — отдельный сценарий R2-07

На клиенте выбрать **«Разные сети»**, получить новый код. Проверяются только
глобальные кандидаты. IPv6 берётся из интерфейсов, внешний IP — через HTTPS ipify,
если включена галочка. Это **адрес выхода запроса**; при VPN/WARP он может принадлежать
провайдеру и не принимать входящие подключения. Для физической общей LAN вместо
этого выбирают **«Одна локальная сеть»**: проверяются её адреса из нового кода.

Для разных сетей без CGNAT нужен заранее обеспеченный входящий TCP 25565 к ПК
хоста либо доступный глобальный IPv6. Помощник не меняет роутер/брандмауэр.
Если мир уже был опубликован на другом порту, HOST_OPEN покажет фактический порт;
проброс должен совпадать именно с ним. Код содержит этот же фактический порт.
При отсутствии этого пути сохранить TARGET_TCP_UNAVAILABLE и оба отчёта.
Отдельный ретранслятор/NAT traversal в network.6 ещё не реализован; сбор нового IP
или DNS не превращает недоступный входящий путь в рабочий сервер.

## Что фиксируется и какие файлы передавать

**«Открыть отчёты»** открывает `%LOCALAPPDATA%\SkyCraft\TestAssistant\reports`.
Обычно `C:\Users\ВАШ_ПОЛЬЗОВАТЕЛЬ\AppData\Local\SkyCraft\TestAssistant\reports`.
Внешний ZIP называется так же, как папка прогона. **Передавать внешний ZIP целиком
с обоих ПК**, а не только вложенный collector.zip или скриншот зелёной строки.

ИТОГИ.txt — читаемые этапы. automatic-results.json — условия, роль, ID и итоги.
initial-state/last-state.json — мир, связь, позиция, причина отказа и peerSession.
environment-before/after.json — процессы/версии, безопасные фильтры winws, WARP
status/settings, IP, DNS, маршруты, выбранные маршруты к кандидатам, слушающие
TCP-порты и драйверы. Координаты/максимальное смещение — в *_RECOVERY_*.json.
CLIENT/HOST_SESSION.json сохраняется также при обрыве/остановке. Дополнительный
сборщик сохраняет версии/хэши и JSONL **именно этого прогона**.

Если ZIP собрать не удалось, программа укажет папку уже собранных файлов.
Заархивировать её Проводником, приложить текст ошибки. collectionErrors означает
неполученные разделы Windows, а не автоматически отсутствие программы/драйвера.

PASS относится к указанному факту; TCP PASS не доказывает вход/HUD/блоки.
FAIL — измерение не прошло. NOT_RUN — не проверялось. PARTIAL — остановлено или
друг не появился. BLOCKED — следующие этапы не выполнены из-за названной причины.
VISUAL_* — оценки человека. Допуск позиции не применим к движущемуся игроку.

По умолчанию не копируются полные логи Minecraft, аккаунты, пароли, токены и
пакеты игры. Причины отказа ограничены, URL и известные поля секретов скрываются.
IP и координаты входят в отчёт; публиковать его на GitHub не требуется — передать
в этот чат. Совместные квесты/NPC Skyrim не проверяются: Skyrim Together Reborn
остаётся отдельной доработкой.

## Самопроверка разработчика

JUnit и Windows-самопроверка помощника; настоящий Minecraft через локальный CONNECT
с явным отказом при входе и проверкой сохранения его причины. Отдельный Minecraft
мир делает три восстановления на отдельном канале памяти; стенд принимает
координаты подобно Skyrim и проверяет отсутствие сброса позиции. Тесты изолированы
от установленных миров. Они не заменяют этот прогон с реальным Skyrim и другом.
