# Проверка network.5 и отдельного EasyLAN, 05.10.2026

## EasyLAN 1.6a-ys.26.3.1

Сборка для Minecraft 26.3 / Fabric 0.19.5 / API 0.161.0+26.3 / JDK 25 прошла.
Семь JUnit-проверок: ONLINE по умолчанию, сохранение OFFLINE/порта/Unicode,
безопасный разбор неверного режима, UTF-8/UTF-16, границы порта/игроков,
сохранность файла при ошибке записи, повреждённый файл настроек.

**Два настоящих клиента Minecraft на одном ПК — PASS.** Хост открыл тестовый
плоский мир в изолированной папке. ONLINE запросил шифрование/авторизацию.
После закрытия LAN режим OFFLINE выбран кнопкой меню; порт/максимум 8 игроков
проверены. Второй автономный клиент дошёл до PLAY, загрузил мир; сервер видел
двух игроков. Проверены Mixin полёта, кнопки настроек/паузы и ZIP отчёта. Меню
ONLINE/OFFLINE также проверено по снимкам, сделанным самим Minecraft.

Установочный пакет: пять проверок — CRC/контрольные суммы, резервные копии и
сохранение аккаунтов/настроек/мира, повторная установка без двух версий мода,
отказ при повреждённом пакете до изменений, отчёт без аккаунтов/миров/полных
логов Minecraft. Проверка выполнена на временной папке, не на установленной игре.

Первоначальные прогоны не были успешными: в пустом профиле vanilla переходит
с выбора мира на создание; это учтено в тесте. Параллельные игры/Gradle также
исчерпали память Windows. Итоговая проверка проведена после освобождения памяти,
без работающего Gradle, с ограниченными JVM и временными файлами в рабочей папке.
Отказ создания сетевого event loop в песочнице не принят за результат игры;
итоговый тест выполнен с доступом к локальным сокетам.

Итоговый комплект: `EasyLAN-Fabric-26.3-1.6a-ys.26.3.1.zip`.
SHA256: `12d83d39bc1b39a5f3174161c8796d0ab4ab548d21f3698ad07e4faecd817d62`.
Инструкция и GPL-исходники включены в ZIP. Это неофициальная адаптация EasyLAN.

## SkyCraft network.5

Добавлены явный выбор ONLINE/OFFLINE хоста для частной сети, передача режима
в SCY2 и сравнение с фактическим сервером. При существующем опубликованном
сервере с другим режимом требуется перезапустить мир; режим не изменяется тайком.
Ожидание мира требует готовой связи/позиции; все отсчёты и ввод движения
сохраняются. Движение во время проверки неподвижности даёт INCONCLUSIVE.

Java-сборка и **67 JUnit-проверок — PASS**. EXE-помощник: **14 самопроверок — PASS**.
Проверен малый распространяемый комплект: контрольные суммы, обновление с
резервной копией, сохранение аккаунтов/настроек/мира, сборщик и среда без ошибок,
отсутствие синтетических секретов, отказ при неизвестной команде.
Протокол shared memory и native DLL 0.1.2 не менялись.

`SkyCraft-AutoTests-0.1.2-ys.network.5.zip` SHA256:
`ffd2aa6e540c2bfc9d7f189e130d3964b0d360ef6fd174ad7657a996ba4e0580`.

**Пределы:** текущая standalone-проверка не подтверждает два Skyrim, работу
через разные ПК, Radmin/WARP/VPN/zapret или CGNAT. Повторное игровое испытание
SkyCraft network.5 с настоящим SKSE и другом ещё требуется. Отдельный EasyLAN
не добавляет NAT traversal или системный прокси. Инструкция повторного прогона:
[YS-RETEST.md](YS-RETEST.md); EasyLAN: [README](../easylan/README.md).
