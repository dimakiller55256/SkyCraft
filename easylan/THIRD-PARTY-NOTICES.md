# Компоненты EasyLAN YS

- EasyLAN 1.6a, XiaoXianHW / Darf: GPL v3. Адаптация YS для Minecraft 26.3
  распространяется как GPL-3.0-only. Полный текст в LICENSE, происхождение в
  UPSTREAM.json, исходники в sources.zip. Изменения перечислены в README.md.
- NanoHTTPD 2.3.1: BSD-3-Clause, Paul S. Hawke, Jarno Elonen, Konstantinos Togias.
  Вложен в JAR для локального HTTP API. Полный текст: licenses/NanoHTTPD.txt.
- Fabric API 0.161.0+26.3: Apache-2.0, FabricMC contributors. Неизменённый
  официальный JAR со своими уведомлениями/лицензиями в META-INF/вложенных JAR.
  Проект: https://github.com/FabricMC/fabric . Apache-2.0: licenses/Apache-2.0.txt.
- Gradle wrapper: Apache-2.0, Gradle Inc.; находится только в исходниках.
  Текст: licenses/Apache-2.0.txt. https://github.com/gradle/gradle .

Minecraft, Java и Fabric Loader не входят в комплект. Требуется собственная
установка Minecraft 26.3 с Fabric. EasyLAN и адаптация YS не связаны с Mojang,
Microsoft или FabricMC и не являются их официальными продуктами.
